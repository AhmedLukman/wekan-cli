# Wekan compatibility

The CLI targets [Wekan v13.28](https://github.com/wekan/wekan/releases/tag/v13.28), commit [9da7639123bc87dac6451d423f1400aa007774a7](https://github.com/wekan/wekan/tree/9da7639123bc87dac6451d423f1400aa007774a7). The [local Compose stack](../compose.yaml) pins the server image by digest. The [API coverage table](api-coverage.md) lists the native operations and corresponding CLI commands. The [interface audit](interface-audit.md) describes the scope of the typed and raw interfaces.

Typed commands reject unknown response fields, missing required values and invalid types, including in nested objects. The CLI reports the native result of each mutation and preserves the selected upload transport and authentication mode.

## Historical defect reconciliation

This ledger follows 63 cases inherited from v11.06, seven reported on v12.57 and the v13.28 findings. Entries marked **Previously fixed** retain their earlier positive regression. **Fixed (source)** identifies repairs established from the tagged implementation. **Release verification pending** identifies cases previously observed live whose relevant v13.28 source was reviewed. Other v13.28 rows include observations from disposable instances using the pinned image.

The maintained Desktop report is `wekan-v13.28-defects.md`. The legacy v11.06 report is historical.
